# 潮汐手札 · Tidewater Notes

一款零依赖的单文件网页垂钓游戏。复古航海手札的视觉，侧视水剖面的场景，玩的是真实的钓鱼节奏：抛竿、等口、提竿、控线。

**在线试玩**：https://tidewater-notes.app.workbuddy.host/?sharecode=AEWMZRZO2O

---

## 这是什么

不是点一下就出鱼的那种钓鱼游戏。一次完整的垂钓要走完四步：

1. **抛竿** — 按住蓄力，力量条来回摆动，松手抛出。落点越远，水越深，虚线轨迹会实时标出「水深 xx.x 米」。
2. **等口** — 浮标轻颤是鱼在试探，沉下去才是真咬。试探时提竿会惊鱼，这条鱼就没了。
3. **提竿** — 浮标下沉后约一秒的窗口，点击画面或按空格。
4. **控线** — 按住收线，把右侧张力压在绿区（24%–78%）。顶到顶会断线，松太久鱼会脱钩；鱼冲刺时张力飙升，得先松手。

上鱼后进入渔获卡：鱼名、学名、重量、水层、潮币，配一张程序化绘制的鱼拓。卖鱼换潮币，去「渔具行」升级鱼竿和鱼线，再往更深的水里找大物。

## 三片水域，二十四种真鱼

| 水域 | 时段 | 特点 |
|---|---|---|
| 溪涧 | 晨 | 水浅流急，马口、白条、宽鳍鱲、溪吻虾虎 |
| 湖库 | 午后 | 四大家鱼的地盘，鲫鲤草鳊鲢鳙，深水有青鱼 |
| 江湾 | 黄昏 | 深水乱石，鳜鱼、黑鱼、鳗鲡、鳡鱼 |

鱼种设定参考公开鱼类志与钓友图鉴整理：栖息水层（上层／中下层／底层）、适钓水深、饵料偏好都有依据。比如鲢鳙滤食要钓浮，青鱼守底啃螺蛳，黑鱼只对雷蛙这类活物起反应。

**水层和饵搭不对会「没口」**：浮标安静地站两秒被收回，提示你换搭配。这是这套玩法里最主要的策略点——不是运气。

## 两条不能商量的规矩

- 钓到**中华鲟**（国家一级）、**胭脂鱼**（国家二级），只有「放流」一个按钮，记入护渔声望。没有带走选项。
- 钓到**罗非鱼**（外来物种）会提醒：请勿放生到自然水域。

## 运行

单文件，无构建、无依赖、无外部请求：

```bash
# 方式一：直接双击 index.html
# 方式二：起一个静态服务（推荐，localStorage 行为更稳定）
python3 -m http.server 8080
# 打开 http://localhost:8080
```

也可以直接把 `index.html` 丢到任意静态托管（GitHub Pages / Netlify / Vercel）。

### 从源码构建

源码按职责拆成三片，由 `build.mjs` 拼成单文件，无第三方依赖：

```bash
node build.mjs        # 读取 src/，输出 index.html
```

| 文件 | 内容 |
|---|---|
| `src/head.html` | `<head>` 与全部样式（设计令牌、布局、响应式、弹窗） |
| `src/body.html` | 页面结构（报头、舞台、控制台、侧栏、弹窗） |
| `src/game.js` | 全部逻辑：数据表、状态机、Canvas 渲染、输入、存档、音效 |
| `build.mjs` | 拼接三段并写出 `index.html`，打印体积与行数 |

## 操作

| 动作 | 鼠标 / 触屏 | 键盘 |
|---|---|---|
| 蓄力 / 收线 | 按住画面或按钮 | 按住空格 |
| 抛竿 / 提竿 | 松开 / 点击 | 松开 / 按空格 |
| 关闭说明弹窗 | 点击按钮 | Esc |

手机端竖屏可用，布局自动切为单列，按钮放大到拇指可及。

## 技术要点

- **单文件**：`index.html` 内含全部 HTML、CSS、JS，约 114 KB，零 CDN、零图片请求。
- **场景**：Canvas 2D 侧视剖面，逐帧绘制天空、水面波纹、光柱、浮游微粒、鱼影、海床卵石与水草；纸张颗粒用内联 SVG 噪声叠加。
- **鱼拓**：不是图片素材，而是 Canvas 程序化绘制——按体型分七类（纺锤、高背、鲶形、鳗形、鲟形、鳢形、虾虎形），生成 dataURL 复用到结算卡与图鉴。
- **音效**：Web Audio 实时合成（抛竿风声、入水、咬钩、断线、上鱼），无音频文件；首次交互后才启动，遵循浏览器自动播放策略。
- **存档**：localStorage（键 `tidewater-notes-v1`），记录潮币、渔具等级、图鉴与最大渔获；采用脏标记落盘，避免无谓写入。
- **性能**：桌面 1440×900、移动 390×844 实测稳定 60fps。

## 关于数值

鱼重、潮币、张力上升速率等数值为玩法服务，不是垂钓指导。鱼种形态与食性参考公开资料整理，若有偏差以专业文献为准。

## 说明

仓库收录三类内容：构建后的单文件成品 `index.html`、可复现它的源码（`src/`）与构建脚本（`build.mjs`）、本说明文档。

Playwright 测试脚本、鱼种覆盖模拟、帧率测量与取图脚本，以及调试截图、`dist/` 发布产物均不在版本库内——它们体积大、可重跑，且与成品无关。`.gitignore` 采用白名单式写法（`/*` 全部忽略后再逐个放行），因此 `git add .` 不会把它们带进来。
